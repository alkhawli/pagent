# PAGENT Untis Chatbot

FastAPI chatbot backed by an Azure AI Foundry model that calls the
[kohlsalem/untis-mcp](https://github.com/kohlsalem/untis-mcp) WebUntis MCP server over stdio.

All application code lives in [backend/](backend/). See [backend/README.md](backend/README.md) for setup, run, and test instructions.
